\# 📥 File Download Simulator



A Java Swing application that simulates downloading multiple files simultaneously using multithreading.



\## ✨ Features



\- Multiple simultaneous file downloads

\- Independent download threads

\- Dynamic download panels

\- Progress bar for each download

\- Random file sizes

\- Download progress displayed in MB

\- Download status updates

\- Simple and clean Swing interface



\## 🛠 Technologies



\- Java

\- Java Swing

\- Multithreading

\- JProgressBar

\- BorderLayout

\- BoxLayout

\- GridLayout



\## 📂 Project Structure



```

src/

├── Main.java

├── MainFrame.java

└── DownloadPanel.java

```
